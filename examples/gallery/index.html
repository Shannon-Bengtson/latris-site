How this page is made

A gallery that rebuilds itself.

Models as code

Each model is a spec.yaml (substrate and sources) plus a build.py (parameters, analyses, evidence checks) in the public latris-examples repo.

Rebuilt on every change

A GitHub Action reruns the build scripts against the current Latris release, re-renders every artifact, and republishes this directory. Update a model, push, and the site follows.

Three ways in

The report for a reviewer, the explorer for someone who wants to interrogate the model, and the story for the person who just wants the answer. Same project underneath all three.

Nothing hand-drawn

Every number on these pages came out of the CLI: estimates, simulations, sensitivity runs. If the model changes and a finding no longer holds, the rebuild makes that visible.
