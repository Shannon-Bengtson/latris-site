Causal DAGs

Identification first, then estimation.

A directed acyclic graph, as used in modern causal inference, writes down your assumptions about what causes what, so you can work out what would have to be measured before an effect could be estimated. Latris answers that question first. With a dataset it will then estimate the effect, and say what the estimate rests on.

At a glance

An arrow claimsThe cause may have a direct effect on the effect, relative to the other variables in the graph.
A missing arrow claimsNo direct effect. These absences are the graph's strongest assumptions.
NumbersNone for identification. With a dataset, an average effect with its confidence interval.
Causal standingIdentification of interventional questions: which variables to condition on so that an effect could be estimated from observational data. An estimate from data is causal only under the graph's assumptions.
In LatrisAcyclicity enforced; d-separation queries; Markov blankets; path enumeration with each path classified; minimal backdoor adjustment sets; effect estimation by adjusted regression.

Where it comes from

Graphical causal models were developed by Pearl and colleagues and set out in Causality (2000; 2nd ed. 2009). Greenland, Pearl and Robins (1999) brought them into epidemiology, where they are now the standard way to reason about confounding, and Hernán and Robins (Causal Inference: What If, 2020) is the standard text. Textor and colleagues' dagitty (2016) is the tool most researchers use to find adjustment sets. Latris's d-separation test follows Shachter's (1998) Bayes-Ball algorithm.

Latris uses the backdoor criterion as Pearl states it. A set Z is a valid adjustment set for the effect of X on Y if no member of Z is a descendant of X, and Z blocks every path between X and Y in the graph with X's outgoing arrows removed.

What practitioners know to watch for

The known problemWhat Latris does
The missing arrows carry the assumptions. Reviewers argue about the arrows that are drawn; the identifying assumptions are the ones that aren't. Every arrow carries its reason and sources, and choices to leave a link out can be recorded as decisions with their rationale, so the absences are on the record too.
Adjusting for the wrong thing. Conditioning on a collider or a mediator opens or blocks paths it shouldn't. Path enumeration labels every path between two variables as a chain, fork or collider, so you can see why a variable belongs in an adjustment set or must stay out. Descendants of the exposure are never offered.
Unmeasured confounding. An adjustment set is only valid if the graph includes the confounders that matter. Latris finds adjustment sets among the variables in the graph and cannot know about variables left out. It also treats every variable in the graph as measurable: marking a variable as unobserved isn't supported yet.
Identification mistaken for estimation. A valid adjustment set says what to control for, not how big the effect is. Latris keeps the two apart. Graph analysis is labelled identification. An effect size comes only from the separate estimation step, on a dataset, with the adjustment set it used, the unadjusted association beside it and its assumptions stated. No counterfactuals.
Feedback in the real system. DAGs can't contain cycles, but many systems feed back on themselves. Latris refuses a DAG with a cycle. Feedback stays in the causal loop diagram view of the same factors; for the DAG, unroll it over time or split the loop.

What Latris implements

  • Acyclicity: a DAG view with a directed cycle is rejected.
  • d-separation: whether two variables are independent given a conditioning set, by Bayes-Ball (Shachter 1998).
  • Markov blankets of any variable.
  • Path enumeration between two variables, each path classified by its chain, fork and collider structure.
  • Adjustment sets: minimal sufficient sets by the backdoor criterion (Pearl 2009), or a statement that no adjustment is needed.
  • Effect estimation: with a dataset, the average effect of one factor on another by backdoor adjustment: the smallest valid set made only of measured factors (or a set you give, checked against the graph), then outcome regression (Hernán & Robins 2020). Ordinary least squares with robust standard errors (MacKinnon & White 1985) for a numeric outcome; logistic regression, as an odds ratio and an average marginal effect, for a two-valued one. The unadjusted association is reported beside it. If every valid set needs a factor the dataset doesn't measure, Latris names what to measure and estimates nothing.

What it doesn't do

  • An estimate is causal only if the graph leaves out no common cause of treatment and outcome, the regression's form is right (linear or logistic, additive, no effect modification) and positivity holds. The report states these every time.
  • Complete cases only, and one numeric or two-valued treatment at a time. No g-computation, inverse-probability weighting or instrumental variables, and no counterfactuals.
  • Minimal adjustment sets are listed up to three variables; the search for a set the dataset measures goes to six. If none exists, Latris says so rather than searching further.
  • No latent or unobserved variables, and no front-door or instrumental-variable identification.
  • Analyses run on the causal links only; other kinds of link in the model are ignored.

On the ladder of causation

The questions a DAG answers are about the second rung, intervention: could this effect be estimated, and by conditioning on what? Latris answers them by graph analysis. With a dataset it estimates an average effect by adjusted regression, which reaches that rung only if the graph's assumptions hold, and the report's methods section says so. It computes no counterfactuals.
