Changelog

What's new.

Releases of the open-source engine that Latris runs on. Want a note when something ships? Sign up for release notes.

0.9.1 10 November 2026

  • Feedback loops now include feedback through stocks, so a causal loop diagram and a system dynamics model in the same project share their loops.
  • System dynamics: set the model's clock (for example, monthly time steps), mark the outcome, and use the standard delay and smoothing functions.
  • Report links keep the model's stated exclusions.
  • The documentation now says plainly what the open-source library does and what the app adds.

0.9.0 9 November 2026

  • Bayesian networks: soft evidence ("80% sure"), the most likely explanation for an observation, and Monte Carlo over the probability tables to show how sure a probability is when the tables are estimates.
  • Methods and foundations: every report gets a methods section that cites only the methods the model used, with their limits. The same source drives the methods page.

0.8.0 9 November 2026

  • System dynamics scenarios: save what-ifs and compare them in one run.
  • Uncertainty: give uncertain values a range, then see Monte Carlo bands and which values the result is most sensitive to.
  • Loop dominance, using the Loops That Matter method: which feedback loop drives the behaviour, and when.
  • Analysis results are recorded and appear in the report with charts, and feed the interpretation.
  • Faster simulation, plus ramp and pulse inputs.

Every version is on PyPI, and the full history is on GitHub.
